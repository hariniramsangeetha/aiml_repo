# Sample Documents

Place your own PDF files here to test the application.

## How to use

1. Copy any text-based PDF into this folder.
2. Run the application: `streamlit run app.py`
3. Upload the PDF from this folder using the sidebar.

## Notes

- Works with any text-based PDF (research papers, textbooks, reports, etc.).
- Does **not** work with scanned/image-only PDFs (OCR not implemented).
- A small PDF (< 5 MB, < 50 pages) is ideal for a quick demo.

## Sample Topics for Testing

You can generate a simple test PDF from any Word document or website using:
- Microsoft Word → Save As PDF
- Any browser → Print → Save as PDF
- Free online tools like Smallpdf or ilovepdf.com
